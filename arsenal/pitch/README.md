# Pitch Arsenal

The pitch layer. Research shows ~40-45% of hackathon scoring is the pitch; this module closes that gap.

## Files

| File | Purpose | Use when |
|------|---------|----------|
| [variants.md](variants.md) | 15s / 60s / 3min / 5min / 30min pitch templates | Writing any pitch |
| [narrative-arcs.md](narrative-arcs.md) | Hero's Journey / BAB / Contrarian — pick one | Before filling a variant template |
| [qa-combat.md](qa-combat.md) | 12 pre-written answers + hostile-question deflections | Any pitch with Q&A |
| [stage-presence.md](stage-presence.md) | Body, voice, slides, broken-demo recovery | Live pitches |

## Writing order (from scratch)

1. Pick an **arc** (`narrative-arcs.md`) — mixing arcs flattens the pitch.
2. Write the **60-second variant** (`variants.md`) — forces category, mechanism, proof, ask.
3. Compress to **15s** and expand to **3-min / 5-min** from there.
4. Prep **Q&A** (`qa-combat.md`) — 3 rehearsal passes minimum.
5. Drill **stage presence** (`stage-presence.md`) — 11 rehearsal passes before demo day.

## Time budget

| Task | First time | With arsenal |
|------|------------|--------------|
| Write 60s + 3min + 5min | 4-6 hours | 60-90 min |
| Prep Q&A (12 Qs) | 2-3 hours | 30-45 min |
| Full rehearsal cycle | 3 hours | 90 min |

**See also:** `../judge-prompts/` for the panel that scores pitches; `templates/pitch-script.md` for a fillable 5-min script with second-level timing.
