# Base Builder Grants — Application Skeleton

**Program:** base.org/builders. Onchain-summer fast-track grants, year-round rolling grants.
**Award:** 1-5 ETH typical; larger strategic grants negotiated.
**Decision:** 1-2 weeks — fastest among major L2s.
**Best fit:** Fast-ship consumer apps, Farcaster-native apps, onchain-summer-themed projects.

## Context

Base grants are fast but small. Treat as **velocity capital** — get funding before you need it, use it to compound. Coinbase's brand + speed make Base grants disproportionately valuable as social proof for follow-on fundraising.

## The Farcaster accelerant

Base / Coinbase heavily favor projects with organic Farcaster presence. Before applying:

- Post about the project as Farcaster casts / frames.
- Tag @base, @jesse.base.eth, @ted, relevant channels (`/dev`, `/founders`).
- Build a Frame that demos the project in-feed if possible.

Projects with visible Farcaster traction skip the queue.

## Outreach

1. DM `@base` on Farcaster or X with link to live product.
2. Build in public — weekly casts.
3. Submit the formal application with links to the public build journey.

## Attachments

- Demo video (30-60s — Base likes short).
- One-page impact summary (optional but read).
- Farcaster engagement screenshots.

## Post-grant

- Publicly thank Base + Coinbase + Farcaster community on cast + X.
- Ship one weekly update cast with progress.
- On milestone completion: request the follow-on milestone tranche.
- Log in `../../career/sponsor-crm.md`.

**Base values: speed, Farcaster presence, consumer UX polish, onchain summer themes. Fastest decision cycle in L2 grants — use it to compound.**
