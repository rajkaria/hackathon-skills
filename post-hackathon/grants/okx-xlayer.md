# OKX X Layer Builder Grants — Application Skeleton

**Program:** X Layer ecosystem. Direct outreach via X Layer Foundation / OKX Web3 BD.
**Award:** 10-50k USDC for qualifying builders; larger strategic grants negotiated.
**Decision:** 2-3 weeks; fast relative to L1s.
**Best fit:** Anything deploying on X Layer, especially agentic, consumer, DeFi infra.

---

## Context

X Layer is aggressively courting builders in 2026. Grants are easier to get than EVM-L1 equivalents but carry weaker brand value. Best treated as **runway-extension capital**, not validation.
