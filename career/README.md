# Career Layer

The compounding layer. Turns the skill from "win this hackathon" into "build a career of hackathons that compound into a company."

**Use when:** Between hackathons. This is where the serial-hackathon flywheel lives — 3 weeks before the next event, you should be in here, not browsing DoraHacks cold.

**Skip if:** This is your first hackathon ever. Win one first, then populate these files with real data.

## Files

| File | Purpose | Updated |
|------|---------|---------|
| [idea-bank.md](idea-bank.md) | Persistent backlog of project ideas with sponsor-fit matrix, validation status, ecosystem tags | Continuously |
| [idea-triage.md](idea-triage.md) | 30-min protocol to pick WHICH idea to build for a specific event. Handoff from bank → execution. 6-axis weighted scoring + kill-filters. | 5-7 days pre-event |
| [sponsor-crm.md](sponsor-crm.md) | Per-ecosystem profiles — grants, judges, contact log, deadlines | Continuously |
| [portfolio-thesis.md](portfolio-thesis.md) | The ONE thesis you ride across 3+ events | Quarterly |
| [score-ledger.json](score-ledger.json) | Per-event: simulated panel score, actual placement, prize, follow-on outcomes | After every event |
| `../retro/` | Per-event retrospective docs + the rule that retros update this skill itself | After every event |

## The Flywheel

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   IDEA BANK ────► PORTFOLIO THESIS ────► SPONSOR CRM       │
│        ▲                ▲                      │            │
│        │                │                      ▼            │
│   RETRO LOOP ◄───── SCORE LEDGER ◄──── HACKATHON EXECUTION │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

- **Idea bank** feeds candidate projects into thesis alignment.
- **Portfolio thesis** filters the bank to ideas that compound.
- **Sponsor CRM** matches filtered ideas to active grants + judges.
- **Hackathon execution** uses the main `SKILL.md` workflow.
- **Score ledger** captures what actually happened — placement, prize, follow-on.
- **Retro loop** updates all four docs + the skill itself.

## The 30-Minute Pre-Event Protocol

Three weeks before a hackathon you've been invited to or spotted on DoraHacks:

1. Open **portfolio-thesis.md**. Check if the event aligns. If not, skip the event. (Saying no is the compounding move.)
2. Open **idea-bank.md**. Filter by the event's sponsor tracks. Pick 2-3 candidates.
3. Open **sponsor-crm.md**. Pull the sponsor's past winners, judge backgrounds, grant follow-ons.
4. Open **score-ledger.json**. Look at the last 3 events — what pattern actually moved outcomes?
5. Write a one-page brief. Lock in ONE idea. Commit to the event or skip it.

Cold brainstorming at hour 0 is the amateur move. The compounding move is filtering a pre-populated bank.
